# nhlambetoSemesterTest_u23645629
I created a data folder with data saved as geojson along with qmd so that I could access the coordinates for my building footprints especially the ones with the syncrest and syncstudy. 

My web interactive map starts off with a search bar and a header and an open street map. I then added all layers that we used in our project, being the Hatfield campus outline, the building footprints, the traffic layers represented as dots for different time frames. It has a popup of the 4 buildings that have sync study and syncrest when you click on the pop up it just tells you that its syncstudy and syncrest. I have also included a popup for the eateries in purple dots, that when you hover over it, the name of the eatery will popup , and the same thing with the bathrooms when you hover over the red dots it will pop up to indicate it as a bathroom. I have also included a layer control where you can switch off and on all the layers that were added into my map. I also added a function that displays the names of the buildings when you hover over them.
